# Historical upstream release notes — archive (not Rincoin)

The files in this folder are the historical **Bitcoin Core** per-version release
notes, inherited from upstream. They are retained for **historical reference
only** — to ease tracing the provenance of upstream changes. They do **not**
describe Rincoin and are not maintained.

For the Rincoin release history, see
[`../release-notes-rincoin.md`](../release-notes-rincoin.md).
