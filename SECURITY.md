# Security Policy

## Reporting a Vulnerability

To report security issues, email **security@rincoin.tech** (not for general support).

Please do not open a public GitHub issue for vulnerabilities that could put users, funds, nodes, or the Rincoin network at risk. If possible, include the affected version, expected impact, and steps to reproduce the issue.

The following key may be used to communicate sensitive information:

--- | ---

You can import the key with:

```sh
gpg --recv-keys FEE1ACA52C65FF3EBF31818CB5595E1752BC2A82
```

Please verify the fingerprint before sending sensitive information.

For non-security bugs, use the [Rincoin Community Core issue tracker](https://github.com/rincoin-community/rincoin-core/issues).
